# 打字比赛 · 抖音/快手双端小游戏

一套代码、双端发布：与 AI 对手竞速打字，看谁又快又准。纯 JS + Canvas，无引擎、无第三方依赖。

## 一、游戏设计

### 玩法
- 开局随机一篇文章（中文名句 / 英文谚语），**系统键盘逐字输入**。
- 打对的字变绿并推进，当前字蓝色高亮；**打错闪红 + 震动 + 自动清空重打**。
- 下方双车道竞速赛道：红色 = 对手(AI)，蓝色 = 你。谁先到终点谁赢。
- 结果页结算：用时、速度(字/分)、正确率、最高连击、段位 S/A/B/C/D、得分。

### 模式与难度
| 项目 | 选项 | 说明 |
|------|------|------|
| 语言模式 | 中文 / 英文 | 中文无标点短句；英文全小写无撇号，减少特殊键 |
| 比赛难度 | 简单 / 普通 / 困难 | 文章越来越长，AI 越来越快（25s/32s/42s 完成一局） |

> AI 难度是"完成整篇文本所需秒数"，数值在 `js/engine.js` 的 `AI_TIME` 里，上线后可按留存数据调整。

### 计分与段位
- 每打对一个字：`10 + 连击加成`（连击上限 50），胜利额外 +500。
- 段位按速度划分（`js/engine.js` `RANK_CN / RANK_EN`，可调）：
  - 中文：S≥120 / A≥90 / B≥60 / C≥36 / D
  - 英文：S≥300 / A≥225 / B≥150 / C≥100 / D（字/分）
- 最高分 `tt.setStorageSync / ks.setStorageSync` 本地持久化。

### 架构（可维护、可扩展）
```
typing-race/
├── game.js                  # 入口：事件绑定 + 主循环(RAF)
├── game.json                # 全局配置（竖屏）
├── project.config.json      # 抖音开发者工具配置（替换 appid）
├── kuaishou.project.config.json  # 快手开发者工具配置模板（替换 appid）
├── js/
│   ├── platform.js          # 平台兼容层：tt/ks 自动检测，缺失 API 降级
│   ├── words.js             # 题库：中/英 × 简单/普通/困难 共 60 篇
│   ├── engine.js            # 核心逻辑：状态机/计分/AI 对手/输入判定
│   └── render.js            # Canvas 渲染：首页/比赛/结算
└── README.md
```

关键设计点：
1. **平台兼容层**：代码里只出现 `Platform.*`，运行时自动识别 `tt`(抖音) / `ks`(快手)，顺带兼容 `wx`(微信)调试。
2. **中文输入法适配**：拼音组词字母串会被忽略（`/^[a-zA-Z]+$/` 过滤），避免把拼音误判为打错；候选词选中后按"最长公共前缀"逐字推进。
3. **英文逐字清空**：每推进一个字符就 `setKeyboardValue('')`，保证连续击键不粘连。
4. **单例布局**：按钮坐标等布局常量定义在 engine，渲染层复用，改布局只改一处。

## 二、本地运行

1. 抖音开放平台 → 创建小游戏 → 拿到 `AppID`（`tt` 开头）。
2. 下载**抖音开发者工具**，导入 `typing-race` 目录，`project.config.json` 的 `appid` 换成自己的。
3. 编译预览（模拟器里用鼠标模拟键盘输入，或直接真机预览扫码）。
4. 快手同理：快手小游戏开放平台建应用 → **快手开发者工具**导入 → 使用 `kuaishou.project.config.json`（改 appid 后替换原配置）。

> 提示：中文模式在真机上用系统拼音输入法体验最佳（选候选词自动推进）；若某输入法把拼音串进输入框，代码已做过滤，仍异常可切换英文模式。

## 三、双端发布要点

| 事项 | 抖音 | 快手 |
|------|------|------|
| 开放平台 | 抖音开放平台 (open.douyin.com) | 快手小游戏开放平台 |
| 开发者工具 | 抖音开发者工具 | 快手开发者工具 |
| AppID | `tt` 开头 | `ks` 开头 |
| 类目参考 | 休闲益智 | 休闲益智 |
| 主体 | 个人可发布；接入广告/支付需企业主体 | 同左 |
| 审核 | 首次约 1~3 个工作日；需隐私合规（用户隐私保护指引） | 同左 |

> 双端**共用同一份业务代码**，只有 `project.config.json` 的 appid 不同；两端各建一个项目目录指向同一源码，或分别打包上传。

## 四、变现与增长（建议优先级）

1. **激励视频复活**：对手快到终点时，看广告让对手停 3 秒 / 或失败后看广告免费再赛一局。
   ```js
   // 抖音
   const ad = tt.createRewardedVideoAd({ adUnitId: '你的广告位ID' });
   ad.show().catch(() => ad.load().then(() => ad.show()));
   // 快手：ks.createRewardedVideoAd 同构
   ```
2. **分享裂变**：结算页"分享战绩"已接入 `shareAppMessage`，可加"分享解锁双倍积分"激励。
3. **排行榜**：接入各端开放数据域/关系链 API，做好友速度榜（驱动复访）。
4. **在线对战**：需要自建服务器（WebSocket），同局文本 + 实时进度同步，是最大留存增量，建议二期再做。
5. **数据埋点**：统计开局率、单局完成率、失败重开率，用于调 AI 难度阈值。

## 六、常见问题

- **模拟器没有键盘**：抖音开发者工具的模拟器提供键盘输入面板；或直接真机预览。
- **中文模式总报错**：确认输入法在"拼音"模式并选择候选词；本代码已过滤纯拼音串。
- **真机上键盘挡画面**：竖屏设计已预留底部回显区；长屏机型自动适配（按 windowHeight 布局）。
